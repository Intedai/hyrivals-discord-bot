## Config
create a .env file and add the following line:  
```
BOT_TOKEN=
```
then add the server_id in the config.toml file.  
You can also modify the bot's colors in the config.toml.

## Run the Bot
sync the project:  
`uv sync`  
run the bot:  
`uv run bot`
